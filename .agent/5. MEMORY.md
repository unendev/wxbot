# MEMORY.md

## Windows 11 下 UIAutomation 的避坑备忘 (Win11 UIAutomation Caveats)

### 1. 微信 4.0 (Qt 架构) 重大变更 (WeChat 4.0 Qt Framework)
* **事实**: 新版微信的进程名已从 `WeChat.exe` 更改为 `Weixin.exe`，窗口类名也从 `WeChatMainWndForPC` 变更为 `Qt51514QWindowIcon`。
* **影响**: 所有依赖 `wxauto` 原版查找逻辑的脚本都会失效。我们必须弃用 `wxauto`，直接使用 `uiautomation` 根据句柄或者类名 `Qt51514QWindowIcon` 进行操作。

### 2. 窗口最小化与隐藏限制 (Window Visibility & Minimization)
* **现象**: 当微信小号窗口被点击最小化，或者点击 X 按钮收纳至系统右下角托盘时，微信主界面窗口的 `Visible` 状态会变为 `0`（隐藏）。此时 UIAutomation 无法在桌面上扫描到它，也无法读取控件树。
* **对策**: 
  1. 必须双击托盘图标，让小号微信的主界面**保持在桌面上显示**。
  2. 可以把小号微信窗口缩到较小尺寸，拖至屏幕边缘，并用其他活动窗口（如浏览器、游戏等）完全遮挡盖住。只要不最小化、不点击关闭到托盘，它的 `Visible` 状态就是 `1`，UIAutomation 即可穿透遮挡进行无感读写。
