## Windows 11 下微信 4.0 自动化最佳实践备忘

### 1. 微信 4.0 (Qt 架构) 特性
* **进程名与类名**: 进程名 `Weixin.exe`，窗口类名 `Qt51514QWindowIcon`。
* **UIA 激活**: Qt 自绘界面需要通过 Windows API `SystemParametersInfoW(SPI_SETSCREENREADER, 1, ...)` 激活无障碍辅助功能，才能稳定暴露内部深层控件树。
* **无障碍树深度**: 控件层级在 25~35 层，搜索深度需设置 `>= 30`。

### 2. 窗口状态要求
* **不能最小化或收起至系统托盘**：若窗口最小化到托盘，`IsWindowVisible` 会返回 `0`，Qt 会销毁或冻结渲染树。必须保持窗口在桌面上还原显示（可被其他窗口 100% 遮挡）。

### 3. SQLite Windows 文件句柄锁避坑
* 在 Windows 下使用 Python `sqlite3` 时，单纯依靠 `with sqlite3.connect(...) as conn` 不会在退出上下文时自动调用 `conn.close()`，必须显式调用 `close()`，否则测试重置或清理临时目录时会报 `[WinError 32] 另一个程序正在使用此文件`。
