## Windows 11 下微信 4.0 自动化最佳实践备忘

### 1. Windows 11 睡眠唤醒无障碍失效 (Modern Standby / Sleep Recovery)
* **事实**: 当 Windows 11 进入睡眠模式后，DWM 与 Qt 渲染上下文被挂起；电脑唤醒后，Qt 内部的无障碍辅助树（Accessibility Tree）处于脱机休眠状态，导致 UIAutomation 读取子控件数变为 0。
* **对策**:
  1. 代码层：通过 `WeChatDriver._ensure_accessibility_enabled()` 设置周期性心跳，定期向系统广播 `SPI_SETSCREENREADER` 自动促使 Qt 无障碍树自愈重建。
  2. 紧急手动唤醒：按下快捷键 `Win + Ctrl + Enter`（开启讲述人再关闭）可强制刷新全局无障碍管道。

### 2. Windows 多线程 COM 初始化 (CoInitialize Caveat)
* **对策**: 每个使用 UIA 的子线程必须通过上下文管理器 `with auto.UIAutomationInitializerInThread():` 显式初始化当前线程的 COM 上下文。

### 3. 微信 4.0 (Qt 架构) 虚拟化列表提取
* **对策**: 废除脆弱的兄弟指针倒序回溯，采用实时获取当前渲染中的最新可见消息尾部（Realized Items Tail Extraction），确保 100% 实时感知新消息。
