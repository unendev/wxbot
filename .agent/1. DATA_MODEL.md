# DATA_MODEL.md

## 1. 领域实体模型 (Domain Models)
* **`ChatMessage` (聊天消息)**:
  * `content: str`: 消息文本内容
  * `sender_type: str`: 发送者角色 (`"user"` | `"bot"`)
  * `msg_type: str`: 消息类型 (`"text"` | `"image"`)
  * `fingerprint: str`: 逻辑哈希 `sha256(sender_type + ":" + msg_type + ":" + content)[:16]`
* **`BotReply` (机器人回复)**:
  * `content: str`: 回复文本
  * `trace_id: str`: 全链路跟踪 ID (`trace_xxxxxx`)
  * `target_chat: str`: 目标会话名称

## 2. 上下文与记忆模型 (Context & Session Memory)
* **`SessionMemory`**:
  * `session_id: str`: 会话唯一标识 (群名称 / 好友微信号)
  * `messages: List[Dict[str, str]]`: 最近 N 轮多轮对话记录
  * `last_active_at: float`: 最后活跃时间戳 (用于 15 分钟 TTL 自然衰减)

## 3. 视觉与多模态模型 (Multimodal & Vision Model)
* **`WeChatImageLocator`**:
  * 自动定位微信本地图片落盘路径（`WeChat Files/FileStorage/Image`）
  * 优先转 Base64 走 `gemini-3.7-flash` 原生多模态视觉看图，降级走 PaddleOCR 提取文本。
