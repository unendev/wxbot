# DATA_MODEL.md

## 1. 微信窗口配置 (WeChat Window Config)
由于是双开微信，我们需要确保底层的 UIAutomation 绑定到正确的微信小号实例。
* **新版微信主进程名**: `Weixin.exe` (微信 4.0 Qt 重构版，而非旧版 `WeChat.exe`)
* **主窗口类名**: `Qt51514QWindowIcon` (基于 Qt 5.15.14，而非旧版 `WeChatMainWndForPC`)
* **目标微信窗口 (Target HWND)**: 机器人小号的微信客户端。
* **绑定群聊 (Target Chat Room)**: `8人小群的名字`（作为过滤条件和定位目标）。
* **置顶状态 (Pin Status)**: 必须在微信中置顶，以方便在未搜索到或异常断开时能快速重新定位。

## 2. 大模型 API 接口定义 (LLM API Payload)
调用 DeepSeek 等大模型的结构。
* **请求地址**: `BASE_URL`
* **API Key**: 从环境变量中读取 `DEEPSEEK_API_KEY`。
* **请求体 (Payload)**:
  ```json
  {
    "model": "deepseek-chat",
    "messages": [
      {"role": "system", "content": "你是一个群聊微信机器人小助手..."},
      {"role": "user", "content": "用户问题"}
    ],
    "temperature": 0.7
  }
  ```

## 3. 表情包/图片数据定义 (Meme Mapping)
映射大模型返回的指令与本地表情包文件的路径。
* **触发关键词**: `[发表情:狗头]` -> `d:/Study/Vue-/wxbot/assets/doge.png`
* **本地图片库映射表 (JSON 逻辑)**:
  ```json
  {
    "狗头": "assets/doge.png",
    "赞": "assets/like.png",
    "哭": "assets/cry.png"
  }
  ```
