# DATA_MODEL.md

## 1. 微信窗口与驱动模型 (WeChat Window Config)
* **进程名**: `Weixin.exe` (微信 4.0 Qt 重构版) / `WeChat.exe` (兼容旧版)
* **窗口类名**: `Qt51514QWindowIcon` (Qt 5.15.14) / `WeChatMainWndForPC`
* **目标会话**: 通过 `WX_TARGET_CHAT` 环境变量配置 (默认 `大丑`)
* **机器人群昵称**: 通过 `WX_BOT_NAME` 环境变量配置 (默认 `小丑`)

## 2. 消息与去重持久化数据模型 (Storage Data Model)
* **SQLite 数据库**: `processed_orders.db`
* **表结构**: `processed_messages`
  ```sql
  CREATE TABLE IF NOT EXISTS processed_messages (
      id TEXT PRIMARY KEY,
      timestamp REAL,
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP
  );
  ```

## 3. 大模型交互 Payload (LLM API Model)
* **接口规范**: OpenAI 兼容协议
* **模型**: `LLM_MODEL` (默认 `gemini-2.5-flash`)
* **消息格式**:
  ```json
  {
    "model": "gemini-2.5-flash",
    "messages": [
      {"role": "system", "content": "系统提示词..."},
      {"role": "user", "content": "用户发言或包含 [图片OCR文字]"}
    ],
    "temperature": 0.7
  }
  ```

## 4. 图像识别与 OCR 数据模型 (OCR Data Model)
* **输入**: 图片路径 / 截图临时文件
* **输出**: 纯文本多行字符串
* **引擎**: PaddleOCR (支持中文、英文、符号高精度提取；未安装时优雅降级)
