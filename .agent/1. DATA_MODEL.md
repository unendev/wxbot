# DATA_MODEL.md

## 1. 领域实体模型 (Domain Models)
* **`ChatMessage` (聊天消息)**:
  * `content: str`: 消息文本内容
  * `sender_type: str`: 发送者角色 (`"user"` | `"bot"`)
  * `msg_type: str`: 消息类型 (`"text"` | `"image"`)
  * `fingerprint: str`: 逻辑哈希 `sha256(sender_type + ":" + msg_type + ":" + content)[:16]`
* **`BotReply` (机器人回复)**:
  * `content: str`: 回复文本
  * `trace_id: str`: 全链路跟踪 ID (`trace_xxxxxx`)
  * `target_chat: str`: 目标会话名称

## 2. 持久化与游标数据模型 (Storage & Cursor Persistence)
* **SQLite 数据库**: `processed_orders.db`
* **表 1 (`processed_messages`)**:
  ```sql
  CREATE TABLE IF NOT EXISTS processed_messages (
      fingerprint TEXT PRIMARY KEY,
      content TEXT,
      timestamp REAL,
      created_at DATETIME DEFAULT CURRENT_TIMESTAMP
  );
  ```
* **表 2 (`session_cursors`)**:
  ```sql
  CREATE TABLE IF NOT EXISTS session_cursors (
      session_name TEXT PRIMARY KEY,
      last_fingerprint TEXT,
      updated_at REAL
  );
  ```
