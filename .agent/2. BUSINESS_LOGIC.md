# BUSINESS_LOGIC.md

## 核心业务闭环流 (Core Closed-Loop Flow)

```
[静默监听 微信 4.0 消息流]
         │
         ▼
[SQLite 查重校验 is_processed?] ── 是 ──> [跳过]
         │ 否
         ▼
[防自循环过滤 (自身发送则标记并跳过)]
         │
         ▼
[消息类型分支判断]
    ├── 纯文本: 直接提取 content
    └── 图片/截图: 若启用 OCR，提取图片内文字
         │
         ▼
[决策大脑 DecisionBrain (LLM 研判/闲聊决策)]
         │
         ▼
[微信纯静默发送 WeChatDriver.send_text_silent]
    (ValuePattern 内存注入输入框 -> InvokePattern 触发发送)
         │
         ▼
[SQLite 标记已消费 mark_processed]
```

### 1. 静默监听 (Silent Listening)
* 周期性（默认 1.5 秒）调用 `uiautomation` 穿透至微信 4.0 消息控件树（`ListControl`）。
* 读取可见子项，构造基于文本与坐标的唯一消息指纹。

### 2. 查重与防死循环 (Deduplication & Loop Prevention)
* 过滤消息发送者：如果是机器人自身发出的消息，自动标记已处理并忽略。
* 结合 SQLite 持久化记录，避免重复回复。

### 3. 图像识别 (OCR Integration)
* 针对图片类消息，保留 OCR 提取能力，解析出图片文本并附带至 Prompt 供大模型综合判断。

### 4. 纯后台无感回复 (Silent Reply Injection)
* 利用 `ValuePattern.SetValue()` 直接将回复内容注入至微信输入框。
* 利用 `InvokePattern.Invoke()` 触发发送按钮，不移动鼠标指针，不抢占前台焦点。
