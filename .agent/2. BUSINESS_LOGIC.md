## 工业级生产者-消费者业务闭环流 (Producer-Consumer Event Flow)

```
       [ 微信 4.0 界面 (Qt/Win32) ]
                   │
                   ▼ (Watcher 线程: 毫秒级轻量无阻塞轮询)
       ┌───────────────────────┐
       │ WeChatDriver.get_tail │ ── 仅读取尾部最后 3~5 条消息
       └───────────┬───────────┘
                   │
                   ▼ (检查逻辑指纹 fingerprint)
         [ 新消息未消费且非自身发言? ] ── 否 ──> [直接跳过]
                   │ 是
                   ▼
         [ 放入 event_queue ]
                   │
                   ▼ (Worker 线程: 防抖合并与调度)
       ┌───────────────────────┐
       │  Debounce & Batching  │ ── 等待 800ms 智能合并连发短句
       └───────────┬───────────┘
                   │
                   ▼
       ┌───────────────────────┐
       │   DecisionBrain (LLM) │ ── 异步调用 LLM (带断路器与 Trace ID)
       └───────────┬───────────┘
                   │
                   ▼
       ┌───────────────────────┐
       │   Silent Dispatcher   │ ── ValuePattern 内存写入
       │                       │    + Win32 PostMessage(VK_RETURN) 穿透投递
       └───────────┬───────────┘
                   │
                   ▼
         [ 更新游标与持久化已读 ]
```
