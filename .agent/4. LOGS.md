### 微信后台静默输入与AI自动回复联调成功
* **变更内容**:
  * 修复了 UIAutomation 的 `EditControl` 上直接调用 `SetValue` 导致的 AttributeError 属性报错，改用标准的 `edit.GetValuePattern().SetValue(text)` 语法进行直接内存值注入。
  * 引入了 `send_btn.GetInvokePattern().Invoke()` 机制触发发送，完全规避了物理鼠标定位。
  * 接入本地大语言模型 API 接口，并针对 API 故障设计了优雅的回声降级回弹（Echo Fallback）机制。
* **发现技术事实**:
  * 通过 `ValuePattern` 进行内存注入完全不需要将输入框聚焦（无需 Focus 状态），也无需任何模拟键盘按键，因此 100% 杜绝了系统级焦点抢占。
  * 微信 4.0 按钮通过 `InvokePattern.Invoke()` 执行完美响应，完全支持无鼠标参与的后台触发。
* **当前状态**: Stage 1、Stage 2 以及 Stage 3 的 AI 文本自动联调成功。开始进入 Stage 3 后续的 clipboard 表情包/图片发送实现阶段。
