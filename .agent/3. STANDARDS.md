# STANDARDS.md

## 1. 绝对红线 (Red Lines)
* **不可移动鼠标**: 严禁在获取消息、发送文本等过程中操纵鼠标硬件指针（不能使用 `pyautogui.moveTo`、`pyautogui.click` 等抢占鼠标焦点的方案）。
* **不可抢占窗口焦点**: 微信小号必须在后台静默运行。严禁调用 `ShowWindow` 并将微信小号强行置于前台（Foreground）。
* **剪贴板极速复原**: 发送表情包需要使用剪贴板。剪贴板的占用必须是瞬时的（< 0.1秒），并在粘贴完毕后立即写回用户之前的剪贴板数据。

## 2. 健壮性与防循环 (Robustness & Loop Prevention)
* **防死循环机制**: 
  1. 机器人不得对自身发送的任何消息（包含带 `@` 的消息）做出响应。
  2. 同一条消息 ID/时间戳 只能被响应一次，防止脚本重启或延迟导致重复回复。
* **异常降级处理**: 如果 API 调用失败，或者微信窗口句柄丢失，脚本需要记录错误并尝试重新连接/绑定，而不能直接崩溃退出。
* **防骚扰流控 (Rate Limiting)**: 单个用户 1 分钟内最多响应 5 次，群内 1 分钟内最多响应 10 次，防止群友刷屏导致 API 额度超支。

## 3. 代码风格与架构 (Code Style)
* 所有的常量（群名、API 密钥、图片路径映射）需要提取到单独的配置文件或环境变量中，避免硬编码。
* 编写清晰的日志模块，分级别（DEBUG, INFO, WARNING, ERROR）输出到控制台及本地日志文件。
