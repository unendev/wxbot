# STANDARDS.md

## 1. 绝对红线 (Red Lines)
* **严禁物理移动鼠标**: 严禁调用 `win32api.SetCursorPos`、`mouse_event`、`pyautogui` 抢占用户的物理鼠标控制权。
* **严禁抢占系统前台焦点**: 微信保持在后台运行，严禁调用 `ShowWindow(hwnd, 9)` 等强行将微信弹到前台打扰用户操作。
* **单一可信源**: 配置统一收敛至 `core/config.py` 与 `.env`，消除分散硬编码。

## 2. 健壮性与去重 (Robustness)
* **幂等去重**: 同一条消息指纹只能响应一次。
* **优雅降级**: 若 LLM 或 OCR 暂时不可用，必须保证捕获异常且守护进程不崩溃退出。
* **安全关闭**: 数据库连接必须通过上下文管理器安全释放，杜绝 Windows 文件锁定（WinError 32）。
