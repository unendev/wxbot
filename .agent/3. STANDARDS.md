# STANDARDS.md

## 1. 架构设计红线 (Architecture Principles)
* **禁止依赖 UI 物理坐标**: 消息去重一律基于逻辑内容哈希（`fingerprint`），严禁使用像素坐标 `(rect.left, rect.top)` 做主键。
* **禁止主线程阻塞**: 监听与大模型网络 I/O 必须通过生产者-消费者队列完全解耦。
* **后台原生消息投递**: 针对非活动后台窗口，使用 Win32 消息级 `PostMessage(hwnd, WM_KEYDOWN, VK_RETURN, 0)` 投递按键，杜绝依赖前台键盘焦点的 `SendKeys`。

## 2. 健壮性规范 (Resilience Standards)
* **全链路 Trace 追踪**: 每一条消息进入系统分配唯一 `trace_id`，日志全链路闭环。
* **断路器保护 (Circuit Breaker)**: 连续 3 次大模型失败自动熔断 30 秒，避免故障雪崩。
* **防抖合并 (Debouncing)**: 自动合并 800ms 内来自同一会话的连发消息，避免机器人刷屏。
